# Carpeta `docs`

Documentación del proyecto Prosta-AI (uso académico y experimental, no diagnóstico).

| Carpeta | Contenido |
|---|---|
| `docsf/` | Documentos originales entregados (Acta, planes, requisitos, diseño, arquitectura y artefactos TSP), organizados por grupo de procesos: 1.1 Inicio, 1.2 Planeación, 1.3 Ejecución y 1.4 Monitoreo y control. |
| `ejecucion/` | Resúmenes en Markdown de los requisitos y del diseño, con las copias de los documentos fuente en `fuentes/`. |
| `gestion/` | Metodología TSP, trazabilidad y registros de cada ciclo (lanzamientos, postmortems, tiempos y defectos). |
| `datos/` | Criterios, elección y fichas de licencia de los conjuntos de datos, y revisiones de los datos. |
| `diseno/` | Diseño del visor y textos de la región de interés. |
| `entorno_desarrollo.md` | Cómo instalar el entorno de desarrollo. |
