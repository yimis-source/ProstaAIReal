# Matriz de trazabilidad de requisitos

Vincula cada requisito con su necesidad, objetivo, entregable, diseño, desarrollo y prueba, para garantizar coherencia durante todo el proyecto.

## Ficha

| Campo | Detalle |
|---|---|
| Paquete EDT | 1.2.1.1 (el mismo archivo se entrega como 1.3.1.2 en Ejecución) |
| Fecha y versión | Versión 1.0 del 08/10/2026 (según su encabezado); archivo marcado «corregida» |
| Autor | Equipo Prosta-AI; propietario: Jair Enrique Sanclemente Castro |
| Formato | Hoja de cálculo XLSX (3 hojas: matriz, catálogo e instrucciones) |

## Contenido principal

* **Estructura:** 32 requisitos en seis grupos, cada uno con estado, criterios de aceptación, complejidad, necesidad, objetivo, entregable (EDT), diseño y desarrollo.
* **Grupos:** 001 gestión con PMBOK y TSP (1.1 a 1.4), 002 legal y ético (2.1 a 2.3), 003 datos y modelo (3.1 a 3.5), 004 funcionales de la aplicación web (4.1 a 4.7), 005 no funcionales (5.1 a 5.4) y 006 diseño, calidad y documentación (6.1 a 6.5).
* **Casos de uso:** los requisitos de la aplicación se relacionan con CU01 a CU06.
* **Catálogo:** códigos N1 a N8 (necesidades del Acta, seis de prioridad alta) y Obj. 1 y Obj. 2.1 a 2.7 (objetivos del proyecto).
* **Mantenimiento:** se actualiza al cerrar cada ciclo y cada pull request cita el ID del requisito.
* **Cobertura:** el [Plan de calidad](plan-de-calidad.md) mide el 100 % de requisitos con implementación y prueba satisfactoria.
* **Vista de ejecución:** el mismo archivo se usa como [matriz de trazabilidad de ejecución](../1.3-ejecucion/matriz-de-trazabilidad.md).
