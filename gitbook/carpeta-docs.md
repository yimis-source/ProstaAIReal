# Carpeta de documentos

Los documentos originales del proyecto (PDF, Word, Excel e imágenes) están en la carpeta `docs` del repositorio de GitHub:

`https://github.com/yimis-source/ProstaAIReal/tree/main/docs`

Junto a cada enlace de este libro aparece la ruta exacta del archivo dentro del repositorio, por ejemplo `docs/docsf/1.1 Inicio/1.1.1 Acta de inicio - Prosta-AI.pdf`.

| Carpeta | Contenido |
|---|---|
| `docs/docsf/` | Documentos originales entregados, organizados por grupo de procesos: 1.1 Inicio, 1.2 Planeación, 1.3 Ejecución y 1.4 Monitoreo y control. |
| `docs/ejecucion/` | Resúmenes en Markdown de los requisitos y del diseño. |
| `docs/gestion/` | Metodología TSP, trazabilidad y registros de cada ciclo. |
| `docs/datos/` | Fichas y revisiones de los conjuntos de datos. |
| `docs/diseno/` | Diseño del visor y textos de la región de interés. |
